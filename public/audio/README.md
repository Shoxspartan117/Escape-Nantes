# Sons des points d'intérêt

Placez ici vos fichiers audio (`.mp3`, `.ogg`, `.m4a`…), par exemple `chateau.mp3`.

Dans l'administration, renseignez le champ **Son** d'un POI avec `/audio/chateau.mp3`
(ou ajoutez `"audio": "/audio/chateau.mp3"` dans le JSON). Le son est joué en boucle tant que la fiche du POI est ouverte.
